# Contributor Covenant Code of Conduct

This project adopts the Contributor Covenant, version 2.1, as its code of conduct. Participants are expected to
uphold a harassment-free, respectful, and inclusive environment. The full text is available at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/ . To report unacceptable behaviour, open a
confidential issue or contact the maintainer through the repository.
